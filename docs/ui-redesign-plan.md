# Let's Talk · UI 重设计方案与下一迭代任务

> 依据：`docs/plan-phase1.md`（实时语音英语对话 · 阶段一）
> 目标用户：小学生（内部使用，主场景 iPad / 触屏电脑，兼容手机）
> 范围：**学生端对话主界面**（`VoiceChat.vue`）整体重设计 + 配套数据/状态小改；管理端只做样式统一（轻量）

---

## 1. 现状诊断（为什么"简陋"）

对照规划文档第 7 节「前端语音模块」的要求（开始/结束大按钮、卡通头像动画、双语字幕、计时、结束反馈），当前 `resources/js/Pages/VoiceChat.vue` 的问题：

| # | 问题 | 现状 | 影响 |
|---|---|---|---|
| 1 | 视觉风格是"后台管理系统" | 灰白卡片 + slate/indigo，圆角小而统一，无品牌感、无童趣 | 目标用户是 7~12 岁孩子，第一眼没有吸引力、不想开口 |
| 2 | 头像用 emoji 充当 | 🎙️/🤖/🎧 切换，只有 scale 呼吸动画 | 无"老师"人格形象；状态区分弱（听/想/说都要靠读字） |
| 3 | 状态反馈靠文字 | 12px 状态徽章 + 顶部小字 | 孩子不会去读；"麦克风是否拾到我声音"完全无反馈 |
| 4 | 场景卡片纯文字 | 名字 + 描述 + L 徽章 + 词片 | 没有插图/配色/主题感，选场景像点菜单 |
| 5 | 会话界面拥挤 | 单元文本、字幕、头像、按钮全塞在一个 3xl 列卡片里，字幕区 max-height 52vh | 沉浸感差；iPad 横屏利用率低；看课文要看不了字幕 |
| 6 | 结束反馈只有一句话 | "练习 X 分钟，共 N 句话" | 规划要求的"结束反馈"形同虚设，没有成就感闭环 |
| 7 | 访客登记是干巴巴的表单 | 两个输入框 + 一个按钮 | 首次体验冷启动差 |
| 8 | 双语字幕是同一串文字 | 中英混排在小气泡里 | 规划要求"双语字幕"，当前实际是单语混排 |

结论：功能闭环已经跑通（录音/推流/打断/字幕/落库都可用），这一迭代**不动音频链路**，专注把同一套状态机"穿上合适的衣服"。

## 2. 设计目标与原则

**一句话目标：让一个二年级孩子，不用读任何说明书，就知道"现在轮到我说话了吗、我说的话它听见了吗、它什么时候会回答"。**

原则（每条都有具体落地）：

1. **大而亮**：主按钮 ≥ 64px 触控区，主色高饱和暖色，孩子扫一眼就抓住重点。
2. **状态一眼可见**：听/想/说三种核心状态用「吉祥物形态 + 舞台光环 + 背景氛围」三重信号表达，不依赖文字。
3. **即时反馈**：孩子说话时**实时音量条/声波动画**（数据已有，见 §6.2），让"麦克风听见我了"这件事看得见。
4. **沉浸少打扰**：会话进行时进入"舞台模式"，场景选择、课文等次要内容收进抽屉。
5. **成就感闭环**：结束页给星星、时长、开口次数、目标词汇回顾——孩子愿意"再练一次"。
6. **克制动效**：动画服务于状态而非装饰；提供 `prefers-reduced-motion` 降级。
7. **零新依赖或极少依赖**：优先 CSS/SVG 自绘吉祥物与动效；字体用 @fontsource 本地打包（离线可用），图标用内联 SVG（可选 lucide-vue-next）。

## 3. 信息架构：一页三屏

Inertia 路由不变（仍是 `VoiceChat` 单页），页面内部按状态机切三个"屏幕"（同一 Vue 页内的子组件）：

```
voice-chat 页面
├─ Screen A 首页：问候 + 吉祥物 + 场景画廊（卡片带插图/配色/难度/词汇）
├─ Screen B 会话舞台（start 之后、end 之前）
│    ├─ 顶部条：场景徽章 · 计时 · 今日配额 · 结束按钮
│    ├─ 中央舞台：吉祥物（听/想/说三态）+ 学生音量电平 + 打断提示
│    ├─ 字幕台：双语字幕流（可折叠课文抽屉）
│    └─ 底部：麦克风状态 + 大按钮
└─ Screen C 结束反馈：星星 + 本次数据 + 目标词汇回顾 + 「再练一次 / 换个场景」
```

访客登记不进屏，而是**首屏的欢迎卡片**（已有 visitor 记录时直接跳过）。

响应式策略：
- **手机竖屏**：单列，舞台在上、字幕在下（当前结构微调）。
- **iPad/桌面横屏（≥1024px）**：左舞台（约 45%）右字幕台（约 55%）双栏，字幕不再限高挤压，孩子看动画时字幕同时在眼前。

## 4. 视觉系统（Tailwind v4 tokens，改 `resources/css/app.css` 的 `@theme`）

### 4.1 配色

暖色为主、每场景一个主题色（存储在 scenarios 表，见 §6.1）：

| Token | 值（示意，实现时定稿） | 用途 |
|---|---|---|
| `--color-sun` | `#FFC53D` 系 | 品牌主色：大按钮、高亮、星星 |
| `--color-coral` | `#FF6B6B` 系 | 强调/结束按钮/错误 |
| `--color-mint` | `#3ECFA3` 系 | 学生气泡、"我在听"状态 |
| `--color-sky` | `#4DA3FF` 系 | AI 气泡、"思考中"状态 |
| `--color-grape` | `#845EF7` 系 | "正在说话"状态、品牌点缀 |
| `--color-ink` | `#2B2B3A` | 正文（不用纯黑，柔和） |
| `--color-cream` | `#FFF9F0` | 页面底色（替换纯白，暖） |

对比度与色盲安全：状态不只用颜色——配套形态/图标（§7 无障碍）。

### 4.2 字体与形状

- 标题/数字：圆润字体，建议 `@fontsource/baloo-2`（拉丁）+ 系统中文（PingFang SC 已够圆润）；若想要中文童趣可加 `@fontsource/zcool-kuaile`，仅用于标题。
- 正文最小 14px（移动）/15px（桌面），字幕 16~18px，英语行距放宽（`leading-relaxed`）。
- 圆角：卡片 `rounded-3xl`，气泡 `rounded-2xl`，主按钮全圆（圆形麦克风钮）；统一大圆角语言，去掉"管理后台直角感"。

### 4.3 动效（`app.css` 定义，纯 CSS + Vue transition）

- 吉祥物：听=轻点头/摇摆，想=旋转小圈+省略号气泡，说=嘴巴开合/声波扩散。
- 舞台光环：listening 时绿色光环呼吸，speaking 时紫色声波涟漪，thinking 时三点闪烁。
- 页面切换（A→B→C）：淡入 + 轻微上移；字幕新消息滑入。
- 全部套 `prefers-reduced-motion` 降级为淡入淡出。

## 5. 各屏详细方案

### 5.1 Screen A · 首页 + 场景画廊

```
┌──────────────────────────────────────┐
│  🦊 嗨，小明！今天想聊点什么？        │  ← 问候条（有昵称）/ 登记卡（无）
│  [今日可用 58:00 ▓▓▓░░]  [EN|中文]    │
├──────────────────────────────────────┤
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ │
│  │ 🍔   │ │ 🐼   │ │ 🎒   │ │ 🚌   │ │  ← 场景卡片：大插图(emoji 2xl)、
│  │餐厅点餐│ │动物园│ │校园生活│ │交通出行│ │    主题色底、L 徽章、目标词片
│  └──────┘ └──────┘ └──────┘ └──────┘ │
│          （点击卡片 = 直接开始）        │
└──────────────────────────────────────┘
```

- 场景卡：主题色渐变底 + 大 emoji 插图（新增 `emoji`/`color` 字段）+ 名称 + L1~L3 徽章 + 3 个目标词片。整卡即按钮，hover/按压有轻微弹跳。
- 访客登记卡：两句话 + 两个大输入框（昵称、年级用**大圆角分段选择**代替下拉，孩子好点），提交按钮即「开始练习」。
- 问候条复用 visitor 昵称；无昵称显示通用欢迎语。
- 语言切换与配额从顶栏并入问候条右侧，不再抢戏。

### 5.2 Screen B · 会话舞台

```
┌──────────────┬─────────────────────────────┐
│ 顶栏（跨栏）  │ 🍔 餐厅点餐 · 12:34 · [结束] │
├──────────────┼─────────────────────────────┤
│              │  📖 课文抽屉（可折叠）        │
│   中央舞台    │ ┌─────────────────────────┐ │
│              │ │ AI 老师  Great! Let's…  │ │
│  🦊 吉祥物    │ │           我  I like…    │ │
│  (三态动画)   │ │  (student 打字中…?)      │ │
│  ✨光环       │ └─────────────────────────┘ │
│  [音量电平条] │                             │
│  「开口即可打断」                            │
├──────────────┴─────────────────────────────┤
│ 底栏：◎ 大麦克风钮（听） / 「结束练习」      │
└────────────────────────────────────────────┘
```

- **顶栏**：左侧场景徽章（emoji+名称，主题色），中间计时器大字，右侧配额迷你条 + 红色「结束」按钮。不再显示"录音已上传 MB"等内部指标（挪到 ended 后或干脆去掉）。
- **吉祥物**：CSS/SVG 自绘小狐狸（或沿用 AI 老师概念做"小助教"形象），替换 emoji。三态：
  - 听（listening）：微笑 + 前倾 + 绿色光环 + **底部音量电平条**随孩子声音跳动；
  - 想（thinking）：歪头 + 头顶"…"气泡 + 旋转小星星；
  - 说（speaking）：嘴巴开合 + 紫色声波涟漪，头像下方提示"点我可打断"。
  - 点击吉祥物 = 打断（保留现有 `interrupt()` 语义，视觉上加可点提示）。
- **音量电平**：新增 `state.micLevel`（0~1 平滑值，来源见 §6.2），画 20~30 段小圆点/柱条，说话时逐级点亮——"麦克风听见我了"的直接反馈，同时天然是权限未授予/音量过低的排障提示（电平一直为 0 → 提示检查麦克风）。
- **字幕台**：
  - 气泡区分：学生=薄荷色靠右、AI=天蓝色靠左 + 头像小图标；**字号加大**（16px+）。
  - 双语呈现：当前文本事件只有一种语言（供应商转写），本轮先做**视觉分层**——英文大行 + 中文辅助行（中文由后端已有翻译能力补时再加；本轮若文本含中文则反之）。作为过渡，气泡上加小语种标签。**如实标注**：双语自动互译依赖供应商转录输出，列为可选增强项（§8 不做项说明）。
  - 说话进行中的占位：AI speaking 且字幕未到时显示"AI 老师正在说…"打字态气泡，避免空白冷场。
  - 课文抽屉：折叠按钮移到字幕台顶部，展开为右侧/上侧滑出面板（横屏时不再挤占字幕高度）。
- **底栏**：中央大圆形麦克风按钮（状态色：听=绿、想/说=灰但可点打断），两侧「结束练习」；按钮文案随状态变（"我在听…" / "听我说…"）。
- 状态文字提示（"开口即可打断"）保留但加大、放在舞台与字幕之间，作为辅助而非唯一信号。

### 5.3 Screen C · 结束反馈

```
        ✨ 太棒了，小明！✨
     ⭐⭐⭐ (按开口句数/时长折算，纯鼓励性)
  本次练习 12:34 · 开口 8 次 · 学到 12 个词
  ┌───────────────────────────────┐
  │ 今天的目标词汇  hello/name/…   │  ← 场景 target_vocab 回顾，点击可听发音(阶段二)
  └───────────────────────────────┘
  [ 再练一次 ]   [ 换个场景 ]
```

- 星星：客户端按 `turn_count(学生回合数)` + `durationS` 简单折算 1~5 星，明确是"鼓励性评价"（真实发音评分是阶段二）。
- 数据行用大数字卡片（时长/开口次数/句子数），词汇回顾用主题色词片。
- 配额条刷新后展示剩余可用时长。

## 6. 需要的数据与代码支撑（小改动，不动音频链路）

### 6.1 场景表加展示字段

- 迁移：`add_display_fields_to_scenarios_table` → `emoji`(string, nullable)、`color`(string, nullable)。
- `ScenarioSeeder` 为现有场景补 emoji（🍔🐼🎒🚌🏫👋…）与主题色名。
- `Api\Voice\ScenarioController@index` 返回这两个字段；`resources/js/lib/api.ts` 的 `Scenario` 接口同步。

### 6.2 状态机暴露麦克风电平

- `useVoiceChat.ts`：`onStudentPcm` 里已有每帧 PCM，用现成 `rmsEnergy()`（`lib/audio/vad.ts`）计算，在 `VoiceState` 增加 `micLevel: number`；用 `requestAnimationFrame` 节流到 ~30fps 写入，并在无输入时向 0 衰减（避免闪跳）。
- 前端组件只读该值画电平条；音频采集/推流逻辑零改动。

### 6.3 组件化拆分（新文件）

```
resources/js/Pages/VoiceChat.vue          # 保留为页面壳：三屏切换 + 状态编排
resources/js/Components/voice/
├── WelcomeHeader.vue      # 问候条 + 语言切换 + 配额
├── VisitorOnboarding.vue  # 访客登记卡（欢迎式）
├── ScenarioGallery.vue    # 场景画廊（含 ScenarioCard）
├── ScenarioCard.vue
├── ChatStage.vue          # 舞台：吉祥物 + 光环 + 音量电平
├── Mascot.vue             # 吉祥物（props: status，内部三态动画）
├── MicLevelMeter.vue      # 音量电平条
├── SubtitleConsole.vue    # 字幕流 + 课文抽屉 + 打字占位
├── SessionTopBar.vue      # 会话顶栏（场景徽章/计时/结束）
├── ChatControls.vue       # 底栏大按钮
├── SessionEndCard.vue     # 结束反馈卡
└── UnitTextDrawer.vue     # 课文抽屉
```

拆分标准：每个组件只依赖 `props` + `useVoiceChat` 全局状态，无内部请求。

## 7. 无障碍与儿童可用性

- 触控目标 ≥ 44×44px（大按钮 64px+）；大按钮带 `active:scale-95` 按压反馈。
- 状态色 + 形态双通道（听=圆形绿光环，说=紫色涟漪+嘴动，想=省略号气泡），色弱可辨。
- 对比度：正文 ink/cream ≥ 7:1；彩色底上的文字用 ink 而非白色小字。
- 动效降级：`prefers-reduced-motion` 全部退化为淡入。
- 文案口语化、短句："点这里开始""开口就能打断它"。

## 8. 本轮明确不做（防止蔓延）

- ❌ 双语自动互译（依赖供应商转录输出形态，需后端翻译链路，留阶段二与"逐句评分"一起做）。
- ❌ 真实发音评分/逐句评价（阶段二，正好复用已落盘双轨音频）。
- ❌ 管理端整体重设计（仅复用新 token 统一配色，1~2 小时顺手做）。
- ❌ 新路由/新页面（Inertia 单页三屏即可）。
- ❌ 音频链路任何改动（recorder/player/uploader/WS 协议一律不动）。
